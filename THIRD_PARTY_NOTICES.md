# OPENRULES Windows candidate notices

The desktop candidate uses dynamically linked Qt 6 Widgets and the Qt Windows
platform plugin from the operator's development kit. The runtime uses SQLite
through rusqlite and IANA timezone data through chrono-tz. The exact Rust
dependency versions and upstream package sources are recorded in Cargo.lock.

This inventory is for local candidate testing. Review the exact distribution
contents, corresponding license texts and notices before redistributing Qt,
compiler runtime files or Rust dependencies. The staged candidate has not
passed the redistribution gate.

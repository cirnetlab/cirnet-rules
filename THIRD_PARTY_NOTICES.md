# Third-party notices

The Rust documentation checker uses the standard library. The retained
scripts use PowerShell 7 and its .NET runtime, Git, or Node.js built-ins.
See [LICENSE](LICENSE).

CI pins [actions/checkout v4.2.2](https://github.com/actions/checkout/releases/tag/v4.2.2).

The engineering principles draw on observations by Andrej Karpathy as
collected by contributors to [andrej-karpathy-skills at 2c60614](https://github.com/multica-ai/andrej-karpathy-skills/tree/2c606141936f1eeef17fa3043a72095b4765b9c2).
That upstream project lists an MIT license. CIRNET's wording is its own.

The former Governance CLI dependency records and notices remain in the
[preserved Governance revision](https://github.com/cirnetlab/cirnet-rules/tree/646afa38516bbfd276b0aecb7a138ab427df5fa9).

# Mẫu bản đồ repository

Chỉ điền mục liên quan từ path và lệnh đã kiểm tra. Dẫn nguồn chuẩn để giảm
dữ kiện sao chép bị lệch theo thời gian.

| Mục | Cần ghi |
| --- | --- |
| Mục đích và ownership | Bề mặt sở hữu, upstream chuẩn và consumer trực tiếp |
| Source và test | Entry point, test lane, lệnh và thư mục làm việc |
| Sinh tự động và bảo vệ | Nguồn/generator, fixture, asset và license |
| Tài liệu | Trang bắt đầu, kiến trúc, chỉ dẫn, reference, lịch sử và changelog |
| Hồ sơ task | Path plan/spec local hiện có và trường hợp cần hồ sơ |
| Output | Vị trí cache, build, log, ảnh được phép và cách cleanup |

Khi di chuyển, kiểm tra import, link, script, CI và lựa chọn package. Xác nhận
đúng chữ hoa thường trên các nền tảng. Giữ đường migration cần thiết.

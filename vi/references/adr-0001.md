# ADR 0001 — Một thẩm quyền governance

**Trạng thái: DRAFT.**

Dùng registry có version trong Git và nguồn chỉ dẫn tiếng Anh làm thẩm
quyền. Đồng bộ bản tiếng Việt để rà soát. Lõi Rust cung cấp phân giải chính
sách, trạng thái task và audit qua CNR và MCP.

Codex Desktop, Claude Code và Antigravity chạy như các coding agent độc
lập. Gói xuất có phạm vi cung cấp chỉ dẫn. Mẫu khởi chạy MCP đã rà soát
kết nối client với kho task cục bộ theo chế độ truy cập được chọn. Thao tác
ghi có quản lý vào repository đã bind cần binding Git đã rà soát, revision
task hiện tại và quyền ghi tường minh theo từng tệp.

Ghi revision governance, binding repository và digest đầu vào cùng bằng
chứng kiểm chứng. Owner sản phẩm giữ quyền sở hữu source, hợp đồng,
artifact và quyết định phát hành.

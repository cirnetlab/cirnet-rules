# ADR 0001 — Một nguồn quản trị

**Trạng thái: DRAFT cho chi tiết triển khai đề xuất.** Baseline, vai trò ngôn
ngữ và audit sản phẩm chỉ đọc là yêu cầu trực tiếp của người dùng.

Kiến trúc đề xuất gồm một registry, một CLI Rust, tiếng Anh chuẩn và nhánh
tiếng Việt tương ứng để rà soát. Loại phương án sao chép riêng theo Agent vì
dễ lệch. Trình cài trong repo sản phẩm sẽ vượt phạm vi ghi. Rust thay các
điểm gọi Python quản trị rỗng. Migration Python sản phẩm là việc downstream.

Họ contract `"0.2"` chỉ kích hoạt khi đã nghiệm thu rõ ràng toàn bộ train
sản phẩm `0.2.4`. Biểu diễn contract, artifact hỗ trợ, IPC riêng và thay đổi
runtime nằm ở repo sở hữu. [Chính sách](../policies/governance.md)

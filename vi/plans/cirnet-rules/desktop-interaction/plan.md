# Kế hoạch tinh chỉnh tương tác và Cài đặt Desktop

[Phạm vi và bằng chứng](../../../specs/cirnet-rules/desktop-interaction/spec.md)

1. Đối chiếu video được cung cấp và chụp bản Windows hiện tại bằng dữ liệu tạm.
2. Thêm kiểm tra hồi quy cho điều hướng, sidebar gọn, control, Cài đặt và vị trí toast.
3. Triển khai thay đổi Qt và lưu giảm chuyển động qua tùy chọn runtime hiện có.
4. Kiểm tra Qt native và offscreen, hồi quy runtime và đồng bộ tài liệu vận hành.

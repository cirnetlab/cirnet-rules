# Kế hoạch thiết kế lại trải nghiệm Dashboard

[Phạm vi và nghiệm thu](../../../specs/cirnet-rules/dashboard-ux/spec.md)

1. Chụp Dashboard Qt hiện hành từ checkout cô lập và dữ liệu tạm.
2. Triển khai khung chia vùng, cài đặt, giao diện, thông báo và tùy chọn SQLite.
3. Cập nhật thao tác chọn repository, hội thoại và tự động hóa, bảo toàn cơ chế cấp quyền.
4. Build, kiểm tra ứng dụng native và chụp kết quả ở các mức tỷ lệ hiển thị được hỗ trợ.

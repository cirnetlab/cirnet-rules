# Kế hoạch khởi chạy desktop

1. Thêm launcher từ source cho Windows và Linux theo bản build native hiện có.
2. Dùng ảnh cú mèo cho nhận diện desktop.
3. Kiểm tra bản build được hỗ trợ và viết hướng dẫn song ngữ.

# Quy trình governance

Dùng `cnr governance validate` ở preflight và trước bàn giao. CI tự chạy kiểm
tra. Review các quy trình này như tài nguyên governance. Gói cấu hình có thể
chứa quy trình để tham khảo. Việc đăng ký và thực thi hook cần ủy quyền riêng
và kiểm chứng native. Xem [hỗ trợ adapter](../adapters/README.md).

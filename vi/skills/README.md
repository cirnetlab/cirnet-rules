# Chọn skill

Dùng danh mục này khi client không có metadata. Bắt đầu từ vai trò hợp task và
chỉ mở vai trò khác khi trigger áp dụng.

- [Kiểm chứng](cirnet-verification/SKILL.md)
- [Biên soạn Work Prompt](cirnet-work-prompt-authoring/SKILL.md) khi có yêu cầu bàn giao
- [Review mã nguồn](cirnet-code-review/SKILL.md)
- [Tái cấu trúc](cirnet-refactoring/SKILL.md)
- [Kiểm thử hồi quy](cirnet-regression-testing/SKILL.md)
- [Tương thích API](cirnet-api-compatibility/SKILL.md)
- [Thay đổi contract](cirnet-contract-change/SKILL.md)
- [Tương thích liên repo](cirnet-cross-repo-compatibility/SKILL.md)
- [Release và changelog](cirnet-release-changelog/SKILL.md)
- [Đồng bộ tài liệu](cirnet-documentation-sync/SKILL.md)
- [Cấu trúc repository](cirnet-repository-structure/SKILL.md)

Implementation, debugging và verification được cài mặc định. Các skill khác
được chọn rõ ràng. Xem [nạp context](../docs/context.md).

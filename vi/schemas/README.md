# Schema quản trị

[Schema registry](../../en/schemas/governance.schema.json) kiểm tra một YAML ở
root. [Schema trạng thái](../../en/schemas/status.schema.json) định nghĩa lớp
bao kết quả CLI. Schema bằng chứng release mô tả đầu vào đề xuất cho repo
sở hữu. Baseline hiện chưa ghi digest ma trận đã duyệt. Remote giữ release-set
và tổ hợp tương thích chính xác. Schema sản phẩm thuộc producer.

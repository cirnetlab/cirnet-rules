# Lệnh dùng chung

Chạy validation trước khi dùng registry. Dùng context với repo, task và mức
rủi ro trong registry. Với mã hoặc contract, đọc audit và plan trả về như
dữ liệu và xin cấp quyền khi phạm vi ghi khác. Dùng các lệnh versions, drift
và release độc lập. Snapshot hiện hành có thể đạt drift trong khi release
bị chặn. Xem [cú pháp](../tools/README.md).

# Nguồn chuẩn tiếng Anh và bản dịch

Giữ path, ID tài liệu, revision, anchor quan trọng và định danh máy tương ứng giữa hai ngôn ngữ. Ghi SHA-256 tiếng Anh đã chuẩn hóa vào metadata tiếng Việt. Cập nhật cả hai trong cùng thay đổi. Kiểm tra hash chưa thay rà soát ngữ nghĩa. So sánh mức bắt buộc, phiên bản, điều kiện an toàn và phát hành theo [thuật ngữ](../references/glossary.md).

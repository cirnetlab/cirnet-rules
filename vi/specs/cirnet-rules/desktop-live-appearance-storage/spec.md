# Giao diện trực tiếp và Lưu trữ

- [x] Chọn phông đã cài cập nhật giao diện và các vùng văn bản đang mở.
- [x] Đổi tiếng Anh, tiếng Việt và tiếng Trung giản thể ngay trên Dashboard đang mở và giữ bản nháp.
- [x] Thẻ chế độ dùng chỉ báo focus bàn phím nét liền trên màu nền tùy chỉnh.
- [x] Lưu trữ tách dung lượng hội thoại, thao tác cơ sở dữ liệu và phản hồi. Các kiểm tra an toàn vẫn có hiệu lực.

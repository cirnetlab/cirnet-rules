# Nghiệm thu chuyển định danh CIRNET RULES

- [x] Build Rust và Qt từ metadata chung đã kiểm tra, xác minh định danh sản phẩm, hiển thị, package và release.
- [x] Kiểm chứng client và runtime IPC riêng không tương thích bị chặn trước thao tác ghi từ Dashboard.
- [x] Kiểm chứng kho mới, kho đời trước, chuỗi di trú cũ, gián đoạn và xung đột bằng fixture.
- [x] Bảo toàn lịch sử SQLite, dữ liệu ứng dụng, tài nguyên gốc và quyền theo phạm vi.
- [x] Kiểm tra soạn thảo và Desktop hiện hành, tài liệu song ngữ, ngoại lệ tên cũ và staging Windows.

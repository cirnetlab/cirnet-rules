# Phạm vi tích hợp Codex Desktop native

ID lượt chạy: `codex-native-e2e-20261112-01`.

Checkout governance cung cấp task store, binding, trình đánh giá grant, verification và audit. Named worktree của repository Interface thật cách ly phép thử. Task setup bao gồm bundle chỉ dẫn Codex đã review và mục MCP cấp dự án. Task sản phẩm riêng bao gồm chỉnh sửa cặp tài liệu.

Nghiệm thu Desktop cần lời gọi MCP thật từ phiên local ở target, task context hiện hành, thay đổi từ phiên đó theo grant chính xác và bằng chứng verification mới. Probe CNR có tầng bằng chứng riêng. Tầng bị chặn hoặc chưa quan sát vẫn được ghi nhận. Chủ thể phê duyệt task, trust dự án và review độc lập cần bằng chứng riêng.

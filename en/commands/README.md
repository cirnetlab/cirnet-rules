# Shared commands

Run validation before using the registry. Use context with a registered repo,
task and risk. For code or contract work, review the returned audit and plan
as data and request authorization when write scope differs. Use the versions,
drift and release commands independently. A current source snapshot can pass
drift while release is blocked. See [syntax](../tools/README.md).

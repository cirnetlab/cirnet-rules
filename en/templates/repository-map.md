# Repository map template

Fill only the relevant fields using checked paths and commands. Link the canonical
source instead of copying facts that will drift.

| Area | Record |
| --- | --- |
| Purpose and ownership | Owned surface, canonical upstream and direct consumers |
| Source and tests | Entry points, test lanes, commands and working directory |
| Generated and protected | Source and generator, fixtures, assets and licenses |
| Documentation | Start page, architecture, instructions, references, history and changelog |
| Task records | Existing local plan/spec path and when records are required |
| Output | Permitted cache, build, log and screenshot locations and cleanup |

For a move, check imports, links, scripts, CI and package selection. Confirm exact
case on platforms that treat names differently. Keep required migration paths.

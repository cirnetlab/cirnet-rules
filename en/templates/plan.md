# Task plan template

Use these prompts under `Plans & Specs` in the task checkpoint. Keep
separate Plan files for durable owner records or derived workflow inputs.

- Objective and authorized repository/file scope.
- Pin relevant durable specifications and decisions by revision and hash.
- Ordered implementation steps with checkable outcomes.
- Verification commands, prerequisites and permitted output locations.
- Documentation impact: affected English/Vietnamese pairs, or reason no update is needed.
- Progress and results: completed work, failures, blocked checks and remaining limits.

Update both language versions after implementation/build. Keep unexecuted checks
NOT_RUN and unmet prerequisites BLOCKED. Record plan changes without implying new
write, release or global-configuration authority.

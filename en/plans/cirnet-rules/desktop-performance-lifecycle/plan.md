# Desktop performance and lifecycle plan

[Scope and acceptance](../../../specs/cirnet-rules/desktop-performance-lifecycle/spec.md)

1. Measure the current Windows build and private SQLite workload. Record video observations separately.
2. Bound Qt transport work and route long runtime storage operations through a cancellable worker.
3. Add typed lifecycle transactions, migrate private databases and connect chat actions and history paging.
4. Connect Configuration, Storage, Archived chats and Appearance to implemented runtime capabilities.
5. Run Windows, SQLite, IPC and governance verification. Record benchmark comparisons, per-case status and remaining boundaries.

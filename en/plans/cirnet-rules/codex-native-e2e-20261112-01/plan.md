# Codex Desktop native integration plan

1. CP1 verifies the checkout and pinned build, reproduces setup proposal validation, and opens the CNR operator interface.
2. CP2 verifies the real Interface repository, creates and binds a separate worktree, and prepares exact setup and product task scopes.
3. CP3 exports and validates the read-only MCP launcher, probes STDIO, and gates project registration on task approval and observed trust.
4. CP4 exposes validated task scopes in the shared context and observes the native Desktop tool calls when the target session is available.
5. CP5 applies the reviewed documentation change from the target Desktop session after a fresh grant assessment. Verify the controlled diff and audit evidence.
6. CP6 runs regression and build gates, records each evidence tier, and saves the resume checkpoint at any host or approval boundary.

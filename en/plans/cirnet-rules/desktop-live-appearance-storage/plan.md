# Live Appearance and Storage plan

[Acceptance](../../../specs/cirnet-rules/desktop-live-appearance-storage/spec.md)

1. Reproduce live typography, language switching, and idle Storage state in Qt tests.
2. Use explicit application typography and a solid keyboard focus indicator for mode previews.
3. Bind interface text to the active translation without rebuilding the window or restarting the runtime.
4. Separate chat usage, database actions, and operation feedback. Verify on disposable data.

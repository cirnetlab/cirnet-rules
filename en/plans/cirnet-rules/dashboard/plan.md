# CGACP Dashboard delivery plan

[Scope and gates](../../../specs/cirnet-rules/dashboard/spec.md)

1. Keep the existing policy and verification entry points. Isolate product release selection from the desktop intake.
2. Add a SQLite catalog and durable intake/job transactions. Verify Git metadata, relink conflicts and restoration on temporary checkouts.
3. Connect an asynchronous Qt desktop through owner-controlled local pipes. Verify folder/file selection, chat history and automation transitions.
4. Exercise the native build, IPC and safety gates on fixtures. Record remaining capability gaps before preparing the application release.

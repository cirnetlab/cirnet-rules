# Dashboard UX redesign plan

[Scope and acceptance](../../../specs/cirnet-rules/dashboard-ux/spec.md)

1. Capture the existing Qt dashboard using an isolated checkout and temporary data.
2. Implement the split shell, settings, themes, notifications and SQLite preferences.
3. Update repository selection, chat and automation interaction without changing authorization.
4. Build and exercise the native application and capture results at supported display scales.

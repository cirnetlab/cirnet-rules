# Desktop appearance customization plan

[Scope and verification](../../../specs/cirnet-rules/desktop-appearance-customization/spec.md)

1. Reproduce the inconsistent font units and scrollbar activation. Define the compatible preference and rendering paths.
2. Add pixel controls, theme-aware color editing and installed font selection. Keep save, reset and conflict handling through the local runtime.
3. Load the selected language at startup and improve the display of status labels and keyboard mnemonics.
4. Verify old and new preferences, live rendering, localization and pointer behavior in a disposable Windows workspace.

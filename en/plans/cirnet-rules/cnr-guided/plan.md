# CNR checks and guided setup plan

1. **CP1** Capture the current Git identity and reproduce missing or malformed input. Share action metadata between CLI preflight and completion. Preserve maintenance command compatibility.
2. **CP2** Build a typed, read-only report using the existing policy, binding, task, audit and verification readers. Exercise invalid authority, missing bindings and scoped Agent evidence.
3. **CP3** Connect the terminal wizard to context selection, bundle export, reviewed managed-block sync and recovery. Require explicit confirmation and keep the existing write grant.
4. **CP4** Validate or register the scoped MCP entry and probe the current CNR server through bounded STDIO. Exercise each adapter with isolated fixtures.
5. **CP5** Verify the regression suite and pinned debug and release builds. Sync the operator guide and record native checks separately.

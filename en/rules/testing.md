# Verification and evidence

Link requirement, affected path, producer revision and test result to a release gate. Record product and governance commits, command, platform, tool versions, exit code, timestamp, result identity and limitations. Verify correctness with conformance tests, reliability with timeout/Stop, security with denial/negative tests, maintainability with boundary and drift checks, performance with owner-approved workload and threshold, and physical safety with independent evidence. Missing input is blocked, not a passing test.

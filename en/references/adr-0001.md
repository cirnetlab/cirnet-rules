# ADR 0001 — One governance authority

**Status: DRAFT for the proposed implementation details.** The user's
baseline, language roles and read-only product audit are direct requirements.

The proposed architecture is one registry, one Rust CLI, English authority
and a mirrored Vietnamese review branch. Alternative per-agent copies were
rejected because they drift. An in-product installer would cross the write
boundary. Rust replaces the empty Python governance entry points. Product
Python migration remains a downstream task.

Contract family `"0.2"` will be activated only after explicit acceptance of the
complete `0.2.4` product train. Contract representation, supported artifacts,
private IPC and product runtime changes remain in the owning repositories.

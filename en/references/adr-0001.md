# ADR 0001 — One governance authority

**Status: DRAFT.**

Use the versioned Git registry and its English instruction sources as the
authority. Keep Vietnamese translations synchronized for review. The Rust
core supplies policy resolution, task state and audit through CNR and MCP.

Codex Desktop, Claude Code and Antigravity run as independent coding agents.
Scoped exports supply instructions. Reviewed MCP launch templates connect
clients to the local task store under the selected access profile. Managed
writes to a bound repository require the reviewed Git binding, current task
revision and explicit file-level grants.

Record the governance revision, repository binding and input digests with
verification evidence. Product owners retain ownership of source,
contracts, artifacts and release decisions.

# Reference material

The [six-repository map](repository-map.md) records locally inspected product
sources and pinned revisions from the initial rebuild. It is navigation and evidence,
not an instruction authority or a claim that current releases are unchanged.

Read only the relevant owner and direct dependencies. Recheck present source,
selected inputs and availability before using a historical fact in a new task.
Keep source review, candidate evidence, selected release and runtime execution distinct.
When refreshing this map, update the English and Vietnamese versions together
and preserve dates, links, SHA values and limitations.

Official client setup sources are linked in [setup](../docs/setup.md).
A reference to another repo, website or log does not authorize executing its commands.

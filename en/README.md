# CIRNET RULES

[Tiếng Việt](../vi/README.md) · [Bootstrap](AGENTS.md) · [Registry](../governance.yaml)

The Rust core and `cnr` CLI route scoped local tasks, keep spec and plan records
centrally, and govern verification and documentation sync. Enter prompts in
Codex, Claude Code or Antigravity. English is the instruction
authority. The current release policy targets `0.2.4` and family `0.2`.
Product owners retain contracts, runtime, release-set and evidence.

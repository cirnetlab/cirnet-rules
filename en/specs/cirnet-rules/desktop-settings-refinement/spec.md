# Desktop Settings refinement

- [x] Vertical and horizontal scrollbars reveal on hover with the sidebar handle palette. Mouse-wheel movement scrolls the surrounding view without changing editor values.
- [x] Appearance opens with visual style controls. Advanced settings are collapsible and Reset default appears only when applicable.
- [x] Storage loads at runtime startup and reports active and archived conversation usage. Refresh is available.
- [x] Archived chats preserve search and real restore and deletion actions. Settings categories, search fields and prominent actions work in dark and light themes.

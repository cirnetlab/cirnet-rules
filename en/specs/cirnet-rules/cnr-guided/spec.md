# CNR checks and guided setup scope

The operator can inspect individual components or an aggregate scope from CLI and TUI. The report records prerequisites, findings, evidence and next actions. Independent checks continue when the authority is unavailable. Checks leave governance and repository state untouched.

One guided setup serves Codex, Claude Code and Antigravity. The operator selects a repository, a confirmed worktree and the Agent. The wizard previews every write and retains reviewed digests in memory. Apply uses the current task grant and preserves user-owned content. A managed entry block has explicit ownership and an auditable rollback.

MCP launch templates, registered configuration, protocol checks and native client behavior are separate evidence. Setup must preserve unrelated configuration and offer manual import where a scoped writer is unavailable. Native discovery requires Agent-specific evidence.

Acceptance uses isolated Git and Agent configuration fixtures. This task covers the current governance checkout. Product checkout changes, user configuration, publishing and release activation require separate authority.

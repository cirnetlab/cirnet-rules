# Desktop appearance customization

- [x] The interface size applies consistently to the workspace, Settings and menus. Advanced uses pixel values for interface text, conversation text, code text and spacing.
- [x] Accent presets and custom RGB colors work alongside editable background and foreground hex values, color pickers, and installed interface fonts. Legacy settings remain readable.
- [x] English, Vietnamese and Simplified Chinese are available. The selected language survives application restart.
- [x] Scrollbar graphics stay the same and reveal only on scrollbar hover or wheel input. Visible status text and shortcut styling avoid unintended underscores.

# CGACP implementation specification

The existing bilingual governance CLI owns release checks and portable
adapters. Its historical six-product audit remains an evidence snapshot.
The local control plane adds independent tasks, scoped routing and evidence.

| Requirement | Acceptance |
| --- | --- |
| CGACP-01–07 | Bind local Git worktrees, route selected paths, guard risk expansion and use source-sensitive context. |
| CGACP-08–15 | Separate task state, grants, controlled steps, verification, review, acceptance and conflict-aware docs sync. |
| CGACP-16–20 | Select release policy explicitly, retain historical tests, preserve adapter limits, enforce budgets and keep all Rust under src. |

Only this repository is an implementation target. Product operations in
verification use disposable fixtures. Existing release and contract
authorities retain ownership. Native Agent discovery and host isolation
require independent evidence.

# Live Appearance and Storage

- [x] Choosing an installed font updates existing interface and text widgets.
- [x] Switching among English, Vietnamese, and Simplified Chinese updates the open Dashboard and preserves drafts.
- [x] Mode previews use a solid keyboard focus indicator on custom backgrounds.
- [x] Storage distinguishes chat usage, database actions, and operation feedback. Existing safety checks remain effective.

# Governance schemas

The [registry schema](governance.schema.json) validates the single root YAML.
The [status schema](status.schema.json) defines the envelope for the CLI.
Release evidence schemas describe proposed owner-side inputs. No approved
matrix digest is recorded at this baseline. Remote retains the release-set
and exact compatibility selection. Product schemas belong to their producers.
[Release policy](../policies/governance.md)
